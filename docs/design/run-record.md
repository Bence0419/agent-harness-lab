# Run record (design decision)

For runs generated by the `ahl` CLI, `run.json` (`ahl-run-v1`) is the canonical, versioned run
record; see `docs/schemas.md`.

The `metadata.json` files written by the research Bash runners come in several legacy shapes
(Pi, OpenCode, verification). They are supported only through a read-only legacy loader. New
runs also emit a derived `metadata.json` (`ahl-metadata-v1`) for tooling convenience, but
application logic must not depend on it: `run.json` is the source of truth.
